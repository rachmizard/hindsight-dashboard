# Product

## Register

product

## Users

Technical operators and developers who manage Hindsight memory banks. They use the dashboard during focused desktop work to inspect stored knowledge, understand entity relationships, review system health, and test recall quality without dropping into API tooling.

## Product Purpose

Hindsight Dashboard turns the Hindsight API into a clear operational workspace. It should make the active bank, system totals, stored memories, entity relationships, and recall results immediately understandable. Success means an operator can move from overview to evidence quickly, keep context while navigating, and trust what the interface is showing.

## Brand Personality

Calm, warm, intelligent. The product should feel considered and conversational without becoming decorative, cute, or casual. It borrows Claude's quiet editorial confidence and clay accent language while retaining its own identity as a dense technical tool.

## Anti-references

- Generic blue-on-black SaaS dashboards.
- Decorative glassmorphism, neon glows, and purple gradients.
- Oversized metric cards that turn routine data into marketing.
- Authentication screens embedded inside the authenticated application shell.
- Starter-template copy, inconsistent component styles, and low-contrast gray text.

## Design Principles

1. Keep the operator oriented: the current bank and current section are always legible.
2. Put evidence before decoration: data, labels, and relationships carry the visual hierarchy.
3. Use warmth with restraint: clay is an interaction signal, not a background wash.
4. Preserve calm under density: spacing, typography, and grouping make complex information scan quickly.
5. Separate product states honestly: authentication, loading, empty, error, and populated states each have a deliberate surface.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Maintain keyboard access, visible focus treatment, readable contrast in light and dark themes, 44px minimum touch targets, semantic form labels and errors, color-independent status communication, and reduced-motion alternatives.
